# Portfolio — Eliot Vion

Portfolio statique en HTML/CSS/JS pour un étudiant en BTS SIO option SISR.

## Structure

- `index.html` : page principale
- `mission.html` : page détaillée des missions de stage, chargée selon `?id=`
- `mission.js` : contenu des 4 missions et emplacements de preuves
- `styles.css` : styles, responsive et illustration de baie réseau du hero
- `script.js` : navigation et animations légères
- `assets/cv-eliot-vion.pdf` : CV

## Missions cliquables

- `mission.html?id=relation-client`
- `mission.html?id=maintenance`
- `mission.html?id=terminaux-mobiles`
- `mission.html?id=wifi`

Chaque page contient une zone « Preuves de réalisation » prête à recevoir des captures, photos, schémas, documents ou comptes rendus.

## Ajouter des preuves

Les cartes de preuve sont volontairement des emplacements. Quand les preuves seront disponibles, remplacer le contenu correspondant dans `mission.js` par les éléments réels à présenter.
